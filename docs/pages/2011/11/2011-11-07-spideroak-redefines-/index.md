SpiderOak [https://spideroak.com/thesupercloud](https://spideroak.com/thesupercloud) _has created a way to bring the cloud into full view - shaping and organizing it into a tool that can help make daily life more efficient._

_We call this approach 'Living the CloudLife' and it is based on four main principles:_

- _Backing up and Storing all of your data - regardless of platform (Mac, Windows, Linux) or remote device (external hard-drive, network volume, USB key)_
- _Synchronizing and/or Sharing any combination of folders across any combination of machines_
- _Accessing all the data you have stored from any machine throughout your network_
- _Consistently maintaining 'zero-knowledge' privacy_
