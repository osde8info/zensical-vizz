Amazon [VM Import](http://aws.amazon.com/ec2/vmimport/ "aws") can now import VMs to EC2 from VMware vSphere, Citrix Xen and M$ Hyper-V.

_VM Import is available at no additional charge beyond standard usage charges for Amazon EC2 and Amazon S3._
