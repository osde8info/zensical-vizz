[BoxGrinder](http://boxgrinder.org/ "boxgrinder") joins [bitnami.org](http://bitnami.org/), [elasticserver.com](https://elasticserver.com/) and [susestudio.com](http://susestudio.com/) software appliance virtual machine builders and _supports many virtualization and Cloud platforms like EC2, Xen, KVM, VMware._

[BoxGrinder](http://boxgrinder.org/ "boxgrinder") can _create appliances based on Fedora, Red Hat Enterprise Linux or CentOS from simple plain text Appliance Definition files._
