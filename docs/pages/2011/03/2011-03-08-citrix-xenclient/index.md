[Citrix XenClient](http://www.citrix.com/English/ps2/products/feature.asp?contentID=2300345 "citrix") is _a high-performance, bare-metal hypervisor that runs directly on the client device hardware, dividing up the resources of the machine and enabling multiple operating systems to run side by side in complete isolation._
