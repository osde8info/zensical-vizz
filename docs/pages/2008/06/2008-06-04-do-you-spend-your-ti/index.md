Billy Marshall (CEO rPath) thinks _that [walled gardens will ultimately be overshadowed by clouds](http://billyonopensource.blogspot.com/2008/04/cloud-computing-casts-shadow-on-walled.html "billy marshall") because you cannot achieve webscale computing if every application has to run on a server owned by Google ... The faster we take the market to cloud computing, the sooner we can kill off the walled gardens through webscale shadows that deprive them of economic sunlight._
