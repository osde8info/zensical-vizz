[VMware Player](http://www.vmware.com/download/player/ "vmware") is free-of-charge software that enables users to easily run any virtual machine on a PC. VMware Player runs virtual machines created by VMware Workstation, VMware Server, or VMware ESX Server and also supports other virtual machines disk formats.
