Using the [MokaFive](http://www.mokafive.com/solutions/how-it-works.php "mokafive") Creator, you can quickly create LivePCs and post them to the entire enterprise with a single click. Share that link with your users to distribute thousands of identical machines. **NOTE**: MokaFive Player for OS X **requires [VMware Fusion](http://www.vmware.com/products/fusion/)** to be previously installed on the host Mac computer.

On a USB device you can boot into [MokaFive Player](http://www.mokafive.com/solutions/downloads.php?it=metalHDPlayer "mokafive") on any computer that allows booting from USB
