[Red Hat and Microsoft](http://www.redhat.com/promo/svvp/?intcmp=70160000000HiHHAA0 "redhat") _have signed reciprocal agreements to enable increased interoperability for the companies' virtualization platforms. Each company will join the other's virtualization validation/certification program and will provide technical support for their mutual server virtualization customers._
