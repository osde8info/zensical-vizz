[VMware Fusion 2.0.2](http://www.vmware.com/support/fusion2/doc/releasenotes_fusion_202.html "vmware fusion") is a maintenance release of VMware Fusion 2 for Apple Mac OS/X.

It now _supports Ubuntu 8.10 as a guest operating system, including features such as VMware Tools with prebuilt kernel modules, Easy Install, and Unity._
