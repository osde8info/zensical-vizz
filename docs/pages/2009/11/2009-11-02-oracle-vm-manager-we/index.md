[Oracle VM](http://download.oracle.com/docs/cd/E11081_01/doc/nav/portal_booklist.htm "oracle") Manager provides a [Web services Application Programming Interface](http://download.oracle.com/docs/cd/E11081_01/doc/doc.21/e10901/wsapi.htm "oracle") (API) to enable integration of third party products with Oracle VM Manager. You can use the API to perform any of the operations in Oracle VM Manager, for example, to create a server pool, add servers, and create virtual machines.
