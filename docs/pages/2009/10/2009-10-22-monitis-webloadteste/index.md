[Monitis' WebLoadTester](http://portal.webloadtester.com/loadtesterhome "monitis") is _a web load and stress testing software as a service that uses cloud computing power for instant web app and network testing. At user request, WebLoadTester adds machines from Amazons server farm to process requested number of virtual users._
