As part of its upcoming 9.10 release, Ubuntu GNU/Linux is set to integrate a number of [new cloud technologies](http://www.internetnews.com/dev-news/article.php/3844066/Ubuntu+Linux+Opening+Up+Cloud+Appliance+Store.htm "ubuntu cloud").

_One of the efforts will include a cloud software appliance store to help expedite setup and deployment of private clouds._
