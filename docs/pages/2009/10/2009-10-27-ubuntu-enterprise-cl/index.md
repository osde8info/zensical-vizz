[**Ubuntu Enterprise Cloud**](http://www.ubuntu.com/products/whatisubuntu/serveredition/cloud/UEC "ubuntu") (UEC) _brings Amazon EC2-like infrastructure capabilities inside the firewall. The Ubuntu Enterprise Cloud is powered by Eucalyptus, an open source implementation for the emerging standard of EC2. This solution is designed to simplify the process of building and managing an internal cloud for businesses of any size, thereby enabling companies to create their own self-service infrastructure._
