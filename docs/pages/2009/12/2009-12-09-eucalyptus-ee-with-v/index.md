[Eucalyptus Enterprise Edition](Eucalyptus Enterprise Edition \(Eucalyptus EE\) with vSphere® "eucalyptus") (Eucalyptus EE) with vSphere® support _enables customers to implement on-premise cloud computing with Eucalyptus, the most popular open source private cloud software, and vSphere, VMware’s industry-leading virtualization platform. Eucalyptus EE with vSphere support is the only on-premise cloud computing solution available today for vSphere customers, providing a robust, affordable cloud computing solution that leverages their investment in VMware® technologies._
