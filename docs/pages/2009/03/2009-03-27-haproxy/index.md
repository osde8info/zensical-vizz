[HAProxy](http://haproxy.1wt.eu/ "haproxy")

HAProxy is a free libre open fast and reliable solution offering [high availability](http://en.wikipedia.org/wiki/High_availability), [load balancing](http://en.wikipedia.org/wiki/Load_balancer), and proxying for TCP and HTTP based applications. It is particularly suited for web sites crawling under very high loads while needing persistence or Layer7 processing.
