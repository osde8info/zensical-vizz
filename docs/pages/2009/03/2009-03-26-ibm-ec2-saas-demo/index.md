[See](http://www.ibm.com/developerworks/offers/lp/demos/summary/wesd-saaswebsmash.html "ibm ec2") how the newly available [IBM® WebSphere® sMash](http://www.ibm.com/developerworks/downloads/ws/ws-smash/ec2.html?S_TACT=105AGY50&S_CMP=DEMOS) and [IBM DB2® Express-C](http://www.ibm.com/developerworks/downloads/im/udbexp/ec2.html?S_TACT=105AGY50&S_CMP=DEMOS) Amazon Machine Images can be used to deploy a sample multi-tenant banking application to the [Amazon Elastic Compute Cloud](http://www.ibm.com/developerworks/offers/lp/demos/summary/wesd-saaswebsmash.html "amazon ec2"). _This demo also explores how the sample application can share its components and deployment infrastructure among multiple tenants._
