[**Eucalyptus**](http://open.eucalyptus.com/ "eucalytptus") - Elastic Utility Computing Architecture for Linking Your Programs To Useful Systems - is an open-source software infrastructure for implementing "cloud computing" on clusters. The current interface to Eucalyptus is compatible with Amazon's EC2, S3, and EBS interfaces, but the infrastructure is designed to support multiple client-side interfaces. Eucalyptus is implemented using commonly available Linux tools and basic Web-service technologies making it easy to install and maintain.

The [**Ubuntu Enterprise Cloud**](http://www.ubuntu.com/products/whatisubuntu/serveredition/cloud/UEC "ubuntu") is powered by Eucalyptus, an open source implementation for the emerging standard of EC2. This solution is designed to simplify the process of building and managing an internal cloud for businesses of any size, thereby enabling companies to [create their own](http://doc.ubuntu.com/ubuntu/serverguide/C/eucalyptus.html "ubuntu") self-service infrastructure.
