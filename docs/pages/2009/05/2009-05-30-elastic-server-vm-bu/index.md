[Elastic Server](http://elasticserver.com/new-server "elasticserver") VM builder is a great new way to build your own software appliances and virtual machines.

You can choose Fedora 10 or Ubuntu 8.04 LTS as your base OS and in a few clicks create Amazon EC2 AMI, ElasticHost, KVM, VMware, Xen VMs !

The VMware VMs that [Elastic Server](http://elasticserver.com/new-server "elasticserver") creates are not just for servers and seem to work fine on VMware Fusion and VMware Player with a nice separate VMDK for your swap file !
