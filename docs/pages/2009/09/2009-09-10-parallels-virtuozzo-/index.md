[Parallels Virtuozzo Containers](http://www.parallels.com/uk/products/pvc45/info/ "parallels") for Linux is _more flexible than many OS Server Virtualization technologies, different Linux distributions may reside on the same physical server._

Supported Host OS Distributions

- [CentOS](http://www.slideshare.net/poustchi/installing-linux-centos-50) 4, 5
- Fedora 7, 8
- [Red Hat Enterprise](http://www.youtube.com/watch?v=3SsG05mMvM8) 4, 5
- SuSE Enterprise Server 10 (also SP1 and SP2)
