What is the openshift origin container application platform ?

OpenShift Origin _is the upstream community project that powers OpenShift. Built around a core of **Docker** container packaging and **Kubernetes** container cluster management, Origin is also augmented by application lifecycle management functionality and [DevOps](https://www.openshift.org/) tooling. Origin provides a complete open source **container** application platform._
