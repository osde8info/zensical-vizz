To follow AWS Identity and Access Management best practises delete your amazon root SSH keys, create IAM users and always use your IAM users to login.

- https://docs.aws.amazon.com/IAM/latest/UserGuide/id\_root-user.html?icmpid=docs\_iam\_console#id\_root-user\_manage\_add-key

and access AWS on a day to day basis via IAM instead of via amazon.co.uk

AWS root login

- https://www.amazon.com/ap/signin?openid.assoc\_handle=aws
- https://console.aws.amazon.com/iam/home#/home
- https://console.aws.amazon.com/iam/home#/security\_credentials

AWS IAM login

- https://us-east-1.signin.aws.amazon.com/oauth?SignatureVersion=4
- https://console.aws.amazon.com/iam/home#/home
