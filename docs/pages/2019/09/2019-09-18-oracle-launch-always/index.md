Oracle launch Always Free Cloud Tier

- https://www.oracle.com/corporate/pressrelease/oow19-oracle-free-tier-091619.html
- https://www.oracle.com/uk/cloud/free/

_Always Free program includes the essentials users need to build and test applications in the cloud: Oracle Autonomous Database, Compute VMs, Block Volumes, Object and Archive Storage, and Load Balancer. Specifications include:_

- _2 Autonomous Databases (Autonomous Data Warehouse or Autonomous Transaction Processing), each with 1 OCPU and 20 GB storage_
- _2 Compute VMs, each with 1/8 OCPU and 1 GB memory_
- _2 Block Volumes, 100 GB total, with up to 5 free backups_
- _10 GB Object Storage, 10 GB Archive Storage, and 50,000/month API requests_
- _1 Load Balancer, 10 Mbps bandwidth_
- _10 TB/month Outbound Data Transfer_
- _500 million ingestion Datapoints and 1 billion Datapoints for Monitoring Service_
- _1 million Notification delivery options per month and 1000 emails per month_
