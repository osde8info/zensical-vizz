oracle virtualbox oracle linux 8 boot iso network install

- Download network boot iso (500M instead of 10G)

- Create VM

- Attach ISO

- Enable Networking

- Enable Network REPO

- Choose your apps

https://yum.oracle.com/oracle-linux-isos.html

https://docs.oracle.com/en/operating-systems/oracle-linux/8/install/install-InstallingOracleLinuxManually.html#l10n-options

Note you must enter the URL for the oracle linux 8 yum repo IN FULL !

```
https://yum.oracle.com/repo/OracleLinux/OL8/baseos/latest/x86_64
```
