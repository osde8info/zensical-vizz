**AWS Management Console Adds Support for Elastic Load Balancing** _AWS has added support for Elastic Load Balancing to the AWS Management Console. Elastic Load Balancing automatically distributes incoming application traffic across multiple Amazon EC2 instances. Now you can use a simple, point-and-click web interface to create and configure load balancers for your Amazon EC2 applications._

_Access to the AWS Management Console is provided free of charge at [https://console.aws.amazon.com](http://www.amazon.com/gp/r.html?R=2CMT1T189TKXS&C=38U7UCPSM0KYY&H=IYRAJZTJBMAQQXLVPCOVRTRKS3CA&T=C&U=https%3A%2F%2Fconsole.aws.amazon.com%3Fref_%3Dpe_8050_14063700)_
