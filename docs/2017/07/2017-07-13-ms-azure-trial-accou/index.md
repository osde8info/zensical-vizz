if you want to try an ms azure trial account (free £20/m credit for one year) you will need to

- sign up for visual studio - https://app.vsaex.visualstudio.com/
- activate your visual studio dev essentials - https://my.visualstudio.com/benefits
- click azure activate
- use IE instead of EDGE as there is a bug in EDGE re credit cards
- enter your tel num and credit card (presumably you wont be charged)
- accept - https://azure.microsoft.com/en-us/support/legal/subscription-agreement/?country=GB
- accept - https://www.microsoft.com/en-us/privacystatement/OnlineServices/Default.aspx

then you can use the ms azure account, portal and pricing sites

- https://account.azure.com/Subscriptions/Statement
- https://portal.azure.com/#dashboard/private
- https://azure.microsoft.com/en-us/pricing/calculator/

and even run wordpress on linux or a blockapps strato ethereum blockchain vm

- https://docs.microsoft.com/en-us/azure/app-service/app-service-linux-readme
- http://developers.blockapps.net/dashboard
