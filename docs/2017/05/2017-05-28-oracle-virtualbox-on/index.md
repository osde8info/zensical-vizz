oracle virtualbox running on windows 10 64bit installed on a pentium dual cpu t2390 will not run windows 10 32bit guests or any 64 bit guests oracle virtualbox will display this error message

```
VT-x/AMD-V hardware acceleration is not available on your system. 
Certain guests (e.g. OS/2 and QNX) require this feature and 
will fail to boot without it.
```

windows 10 32 bit and 64bit will also hang during install on a amd sempron 3500+ mobile cpu maybe for a similar reason
