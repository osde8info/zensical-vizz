[VirtualBox Personal Use](http://www.virtualbox.org/wiki/Licensing_FAQ "virtualbox") is

_when you install the product on one or more PCs yourself and you make use of it (or even your friend, sister and grandmother)._

_Also, if you install it on your work PC at some large company, this is still personal use._

_However, if you are an administrator and want to deploy it to the 500 desktops in your company, this would no longer qualify as personal use._
