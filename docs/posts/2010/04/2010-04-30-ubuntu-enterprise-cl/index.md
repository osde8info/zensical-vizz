In archive.org's [open source audio](http://www.archive.org/details/opensource_audio "archive.org") library you can now find a [Ubuntu Enterprise Cloud (UEC) oggcast](http://www.archive.org/details/Tlf-TheUbuntuEnterpriseCloud "archive.org") from [Dustin Kirkland](http://www.archive.org/search.php?query=creator%3A%22Dustin%20Kirkland%22) at the Texas LinuxFest 2010.

_You will witness the ease of deploying an Ubuntu Enterprise Cloud (UEC), Canonical's open source implementation of an Amazon EC2-compatible cloud that you can run locally, in your data center and on your own hardware._
