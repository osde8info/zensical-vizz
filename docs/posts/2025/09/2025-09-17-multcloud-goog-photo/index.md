Google has updated the Google Photos API as of 7 May 25.

To accommodate these changes, there are the following updates:

The "Albums" folder will now only display albums created by MultCloud.  
The "Photos" folder will now only display images uploaded via MultCloud.

To transfer images from Google Photos to other Cloud services, please click the "Add More Photos" button and grant MultCloud access to the images you wish to transfer.

To transfer images from other cloud services to Google Photos, please note that only folders can be transferred to the "Albums" folder, and only individual images can be transferred to the "Photos" folder.
