[Patrick Kerpan](http://www.cohesiveft.com/patrickkerpan/ "cohesiveft") gave a great talk this evening on [Elastic Server](http://elasticserver.com/ "elastic server") Bundles. You can just search for a component name such as [java](http://elasticserver.com/bundle-explorer?query=java&rating=0&official_filter=cft&distro=4&commit=Search&official_filter=cft&only_latest_versions=true "elastic server") to get a list of bundles which you can then add to your server template and then create your Server image on a variety of virtualisation and cloud platforms. I particularly liked the idea of using [Elastic Server](http://elasticserver.com/ "elastic server") to create KVM images for your dev team, VMW images for your test team and AMI for operations / production !
