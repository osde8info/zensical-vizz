[JumpBox Cloud Gear](http://www.jumpbox.com/cloud-gear "jumpbox") _lets you run any JumpBox in minutes using Amazon EC2 and gives you instant access to a broad array of Open Source web applications with just a few mouse clicks. There's no upfront cost to use them and you only pay for your actual usage. The minimum time increment is one hour and that opens up all kinds of use cases that would normally be prohibitive._
