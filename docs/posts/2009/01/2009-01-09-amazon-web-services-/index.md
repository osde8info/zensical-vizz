The [AWS Management Console](https://console.aws.amazon.com/ "aws") gives you a quick, global picture of your cloud computing environment so that you can see what resources you're operating and conveniently manage those resources. The initial release of the AWS Management Console provides a graphical user interface for Amazon EC2.

There even a [AWS GUI video tutorial](http://media.amazonwebservices.com/console/AwsConsole.html "aws") you can watch
