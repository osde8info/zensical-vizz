[Parallels Server BETA](http://www.parallels.com/products/server/wl/ "parallels") is a bare metal cross-platform hypervisor virtualization solution that can be installed on most Intel-based computers with Intel VT-x or AMD-V hardware virtualization support that have Mac OS X, Windoz, GNU/Linux, or no primary operating system installed.
