The [OpenVZ project](http://wiki.openvz.org/News/announcements/Ubuntu_Virtual_Appliance_20080109 "openvz") have released virtual appliance software for Ubuntu giving users the ability to run the popular Ubuntu 7.10 distribution in a Linux container. Users simply download a [template](http://openvz.org/download/template/cache "openvz") and then can use OpenVZ software to create a virtual server running Ubuntu 7.10 in about **one minute** !
