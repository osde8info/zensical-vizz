The [Open Cloud Manifesto](http://www.elasticvapor.com/2009/03/introducing-open-cloud-manifesto.html "elasticvapor") goal is to draft a document that clearly states we (including dozens of supporting companies) believe that like the Internet, the cloud itself should be open. The manifesto does not speak to application code or licensing but instead to the fundamental principles that the Internet was founded upon - an open platform available to all.
