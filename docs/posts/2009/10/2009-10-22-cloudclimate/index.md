[CloudClimate](http://www.cloudclimate.com/ "cloudclimate") displays monitoring results from a globally distributed installation of PRTG Network Monitors on Amazon, CloudLayer, GoGrid, RackSpaceCloud, Softlayer clouds. PRTG works with one core server installation and a number of remote probes used to measure system performance and to remotely monitor performance of network services.
