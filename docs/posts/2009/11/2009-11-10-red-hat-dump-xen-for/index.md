The latest announcement from Red Hat about [Red Hat Enterprise Virtualization](http://www.redhat.com/virtualization/rhev/server/ "red hat ") [for Servers](http://www.redhat.com/virtualization/rhev/server/ "red hat ") says [Red Hat Enterprise Virtualization](http://www.redhat.com/virtualization/rhev/server/ "red hat ") features a _unique and revolutionary virtualisation technology called KVM_ and that they have virtualised a workload of 12.5 VM's per core (ie 400 VM's) using a 32 core 1TB server ! And unlike Oracle Xen VM Server, [Red Hat Enterprise Virtualization](http://www.redhat.com/virtualization/rhev/server/ "red hat "), includes SELinux secuirty technology !
