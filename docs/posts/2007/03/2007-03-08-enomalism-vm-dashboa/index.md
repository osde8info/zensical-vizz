The [**Enomalism Virtualized Management Dashboard**](http://www.enomalism.com/Features.144.0.html) (VMD) is a powerful open source, web-based virtual machine manager for the XEN hypervisor. Designed to answer the challenges of fragmented hosting environments, Enomalism provides an easy to use interface to provision concurrent isolated servers using the Enomalism Virtualized Grid environment and the [**Elastic Computing Platform**](http://enomalism.com/314.0.html) .
