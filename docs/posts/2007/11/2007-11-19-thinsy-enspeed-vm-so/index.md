[**Thinsy EnSpeed VM Software**](http://www.enspeed.com/virtualization.html "enspeed") provides the capability to run unmodified guest OSes such as Windows, in a cluster of Physical Machines (VMM Servers).

EnSpeed Virtual Appliances are targeted at end users, not system administrators and full GUI configuration is included with all Virtual Appliances.
