[AppLogic](http://www.3tera.com/Technology/index.php "applogic") is a grid operating system that is designed for web applications and is optimized for transactional and I/O intensive workloads.

_It uses advanced virtualization technologies to ensure complete compatibility with existing operating systems, middleware and applications. As a result, AppLogic makes it easy to move existing web applications onto a grid without modifications._
