Using [MySQL Enterprise for Amazon EC2](http://www.mysql.com/products/enterprise/ec2.html "mysql"), developers can cost-effectively deliver web-scale database applications in the "cloud", fully backed by the database experts at MySQL.

_Amazon EC2 and MySQL are a great fit for organizations that want to reduce the capital expenditures and operating costs required to build out and run their IT infrastructure._
