With the release of VMware Player 5 VMware have made it no longer free-of-charge for office use only personal use. So you'll have to switch to [VirtualBox](https://www.virtualbox.org/ "virtualbox") or be sure to download VMware Player 4 instead and do not upgrade it !

_VMware Player 5 is now available for commercial use with support offerings as a component of [VMware Fusion Professional](http://www.vmware.com/products/desktop_virtualization/fusion/professional.html)._
