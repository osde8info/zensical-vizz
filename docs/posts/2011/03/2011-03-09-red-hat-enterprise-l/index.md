[Red Hat Enterprise Linux 5.6](http://press.redhat.com/2011/01/13/red-hat-enterprise-linux-5-6-now-available/ "red hat") includes _support for sVirt (SELinux virtualization), which enables Mandatory Access Control (MAC) profiles to be applied to virtual guests, enhancing overall system security._
