[Gartner Magic Quadrant for Web Hosting and Hosted Cloud System Infrastructure Services](http://mediaproducts.gartner.com/reprints/gogrid/article2/article2.html "gartner cloud") (On Demand)

_Web hosting is rapidly converging with cloud system infrastructure services. For the last several years, the market has been evolving toward on-demand infrastructure provisioned on a flexible, pay-as-you-go basis, but the introduction of cloud computing offerings has radically accelerated innovation in this market._
