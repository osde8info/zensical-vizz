[SpringSource Cloud Foundry](http://www.cloudfoundry.com/ "cloudfoundry") is the first self-service, pay-as-you-go, public cloud deployment platform for full-feature Java web applications that unifies the entire build, run, and manage application lifecycle for Java. Cloud Foundry offers complete application lifecycle management for running Spring, Grails, and Java web applications by integrating the world's most popular Java web application technologies into an enterprise Java cloud platform that takes full advantage of the power of elastic cloud computing.
