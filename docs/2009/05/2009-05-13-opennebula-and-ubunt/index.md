[**OpenNebula** on Ubuntu](http://doc.ubuntu.com/ubuntu/serverguide/C/opennebula.html "ubuntu") allows virtual machines to be placed and re-placed dynamically on a pool of physical resources. This allows a virtual machine to be hosted from any location available.
