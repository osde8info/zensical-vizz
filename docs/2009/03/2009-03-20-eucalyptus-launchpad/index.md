[EUCALYPTUS](https://www.ohloh.net/p/eucalyptus "ohloh") - Elastic Utility Computing Architecture for Linking Your Programs To Useful Systems - is an open-source software infrastructure for implementing "cloud computing" on clusters.

The current interface to EUCALYPTUS is compatible with Amazon's EC2 interface, but the infrastructure is designed to support multiple client-side interfaces.

EUCALYPTUS is now on [Launchpad](https://launchpad.net/eucalyptus "launchpad")
