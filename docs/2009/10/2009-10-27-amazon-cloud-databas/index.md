[Amazon Relational Database Service](http://aws.amazon.com/rds/?ref_=pe_12300_13473310 "amazon") (Amazon RDS) is a web service that lets you set up, operate, and scale a MySQL relational database in the cloud. _Amazon RDS gives you access to the full capabilities of a familiar MySQL database. This means the code, applications, and tools you already use with your existing MySQL databases will work seamlessly with Amazon RDS._
