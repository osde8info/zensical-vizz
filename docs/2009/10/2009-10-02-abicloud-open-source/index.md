[Abicloud](http://www.abiquo.com/ "abiquo") is an open source infrastructure software for the creation and integral management of Public & Private Clouds based on heterogeneous environments. The tool mainly offers users the capacity for scaling, management, automatic and immediate provision of servers, storage, networks, virtual network devices as well as applications.
