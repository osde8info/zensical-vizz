[Canonical Ubuntu Project Landscape](http://www.canonical.com/projects/landscape "canonical") simplifies the process of managing Cloud environments by allowing you to manage them as you would physical machines. _Users can now start, stop, manage and monitor Ubuntu instances on the Amazon EC2 cloud environment from within Landscape. Manage and Monitor instances of Ubuntu from within Landscape Landscape works equally well with preconfigured Ubuntu images on Amazon EC2 or manage your own custom images. Manage Virtual Cloud instances and your physical systems on the same page in Landscape_
