[JumpBox Sakai](http://www.jumpbox.com/app/sakai "jumpbox") is an Open Source collaborative learning environment that contains everything necessary to deliver an effective eLeaning program. The JumpBox packages the [rSmart](http://www.rsmart.com/products "rsmart") distribution of [Sakai](http://sakaiproject.org/portal "sakai") which is a refined version of the Open source Sakai project with enhancements like additional modules and an improved user interface. [Sakai](http://sakaiproject.org/portal "sakai") can be used to deliver an entirely online learning experience or used as a supplement to traditional in-person coursework.
