[Virtual Iron](http://www.virtualiron.com/products/index.cfm "virtualiron") provides enterprise-class software for [server virtualization](http://www.virtualiron.com/products/Server_Virtualization.cfm) & [virtual infrastructure management](http://www.virtualiron.com/products/Virtual_Infrastructure.cfm).

The [Virtual Iron](http://www.virtualiron.com/products/index.cfm "virtualiron") product offers comparable capabilities and performance to established proprietary offerings.

In keeping with the GPL, you are welcome to use the [Open Virtual Iron](http://www.virtualiron.com/products/open_source.cfm "open virtual iron") sources in whatever way you wish. Please keep in mind that Virtual Iron only supports the binaries shipped with the product for the operating system versions on their [supported list](http://www.virtualiron.com/products/System_Requirements.cfm).
