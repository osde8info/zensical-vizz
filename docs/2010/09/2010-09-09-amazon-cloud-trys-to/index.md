[Amazon EC2 Cloud](http://aws.amazon.com/ec2/ "amazon") are now trying to undercut [OVH Cloud](http://www.ovh.co.uk/cloud/devcloud.xml "ovh") pricing

_Amazon EC2 Micro instances area new, low cost instance type designed for lower throughput applications and web sites. Amazon EC2 Micro instances provide 613 MB of memory and support 32-bit and 64-bit platforms. [Amazon EC2 EU Micro instance pricing](http://aws.amazon.com/ec2/?ref_=pe_2170_16832160 "amazon") for On-Demand instances starts at $0.025 per hour._
