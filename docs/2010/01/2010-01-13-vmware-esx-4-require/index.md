date: 2010-01-13

tags: 
  - "vmware"
---

[VMware ESXi 4.0](https://www.vmware.com/tryvmware/p/download.php?p=free-esxi&lp=1 "vmware") is certified to run on a broad range of 64-bit hardware. Check the [Hardware Compatibility List](http://www.vmware.com/resources/compatibility/search.php) to ensure that the server model you intend to use is certified to run VMware ESXi 4. For 32-bit hardware support, download the previous version, [VMware ESXi 3.5](https://www.vmware.com/go/getesxi/).
