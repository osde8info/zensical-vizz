[Cloudmin 4.7](http://webmin.linux-mirror.org/cloudmin.html "cloudmin")

_adds the ability to install an Xen or KVM instance from a CD, supports partitioned Xen disks and Xen HVM mode, allows you to edit the boot device for virtual systems, supports changing the media type for virtual disks, adds a notes text box for systems, and many other changes._

[Cloudmin GPL](http://www.virtualmin.com/documentation/cloudmin/ "cloudmin")

_does not contain all of the features of the Pro version, and is limited to managing a single Xen host system._
