## [libvirt](http://libvirt.org/ "libvirt") is:

- _A toolkit to interact with the virtualization capabilities of recent versions of Linux (and other OSes)._
- _Free software available under the_ [_GNU Lesser General Public License_](http://www.opensource.org/licenses/lgpl-license.html)_._
- _A long term stable C API_
- _A set of bindings for common languages_
- _A_ [_CIM provider_](CIM/) _for the DMTF virtualization schema_
- _A_ [_QMF agent_](/qpid/) _for the AMQP/QPid messaging system_
