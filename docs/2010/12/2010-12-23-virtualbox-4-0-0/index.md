[VirtualBox](http://www.virtualbox.org/ "virtualbox") 4.0.0 is a major update and includes the following [major new features](http://www.virtualbox.org/wiki/Changelog "virtualbox"):

- _Reorganization of VirtualBox into a base package and Extension Packs_
- _New settings/disk file layout for VM portability_
- _Major rework of the GUI (now called “VirtualBox Manager”):_
- _Redesigned user interface with guest window preview (also for screenshots)_
- _New virtual hardware Intel ICH9 chipset with three PCI buses, PCI Express and Message Signaled Interrupts (MSI)_
- _Intel HD Audio, for better support of modern guests_

According to [LifeHacker](http://lifehacker.com/5716728/virtualbox-40 "lifehacker") you can even [use VirtualBox to run a Mac OS-X guest](http://lifehacker.com/5583650/run-mac-os-x-in-virtualbox-on-windows "lifehacker") !
