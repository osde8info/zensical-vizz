IBM Cloud IBM BlueMix CLI only works on Ubuntu it cannot be installed on CentOS or Red Hat

```
$ curl -sL https://ibm.biz/idt-installer | bash

[main] --==[ IBM Cloud Developer Tools for Linux/MacOS - Installer, v1.2.3 ]==--
[main] WARN: Linux has only been tested on Ubuntu, 
please let us know if you use this utility on other Distros
```
