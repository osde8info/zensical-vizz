linuxlite is a great (LXDE/XFCE based) guest os for virtualbox and vmware player since vboxclient tools are preinstalled and you just need to run aptitude install open-vm-tools for vmware workstation player

- https://www.linuxliteos.com/
- https://github.com/vmware/open-vm-tools
