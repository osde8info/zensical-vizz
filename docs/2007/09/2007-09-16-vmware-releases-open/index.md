VMware has just released a majority of VMware Tools as open source software as part of the project Open Virtual Machine Tools. VMware Tools is a set of guest operating system virtualization components that enhance performance and improve management of VMware virtual machines.

Open Virtual Machine Tools (open-vm-tools) is hosted at [http://open-vm-tools.sourceforge.net](http://open-vm-tools.sourceforge.net/), and the source code is available today to enable Linux vendors to integrate open-sourced VMware Tools into upcoming versions of their operating systems.
