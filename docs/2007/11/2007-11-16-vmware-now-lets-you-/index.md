title: "VMware now lets you force VMs into BIOS setup mode on bootup"
date: 2007-11-16
categories: 
  - "vizz"
---

Apparently VMware Server 2 beta lets you force VMs into BIOS setup mode :

```
- go to you VM with the VI client
- stop the machine
- then Options tab
- then "Boot options"
- check "Force BIOS setup".
```
