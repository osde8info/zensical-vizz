Amazon have just added support for [Amazon Simple Queue Service](http://aws.amazon.com/sqs/ "amazon") (Amazon SQS) to the AWS Management Console.

_Amazon SQS offers a reliable and highly scalable queue-based messaging service which supports distributed application and makes it easy to exchange time-sensitive data between components or EC2 instances._
