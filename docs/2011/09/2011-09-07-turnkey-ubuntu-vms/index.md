[TurnKey Linux](http://www.turnkeylinux.org/ "turnkey") claim to have pre-built 45 Ubuntu VMs than can run on Amazon EC2, VMware, VirtualBox, Parallels and Citrix Xen ! The main advantage of a  [TurnKey Linux](http://www.turnkeylinux.org/ "turnkey") VM is that they all include [TKLBAM](http://www.turnkeylinux.org/docs/tklbam) which can backup any VM to Amazon S3 !
