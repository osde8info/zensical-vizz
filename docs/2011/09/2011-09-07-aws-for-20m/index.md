According to the [AWS Price Calculator](http://calculator.s3.amazonaws.com/calc5.html "aws price calculator") and the [AWS Price List](http://aws.amazon.com/ec2/pricing/ "aws prices") you can now get started on Amazon AWS for less than $20/m if you choose a [AWS Micro AMI](http://aws.amazon.com/ec2/instance-types/ "aws ami") instance with no storage:

- 613M of memory
- 0G 'EBS' storage

will cost ~ $19/m

However a more useful a [AWS Standard AMI](http://aws.amazon.com/ec2/instance-types/ "aws ami") instance:

- 1.7G of memory
- 160 GB 'instance' storage

will cost ~ $70/m
