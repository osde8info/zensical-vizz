when you create a centos, oel or ubuntu vm on @oracle #oci you can enable the oracle cloud agent (oca) which has:

- Vulnerability Scanning - Scans the instance for security vulnerabilities.
- Management Agent - Collects data from resources such as OSs, applications, and infrastructure resources for OCI services that are integrated with Management Agent. Data can include observability, log, configuration, capacity, and health data.
- Custom Logs Monitoring - Ingests custom logs into the Logging service.
- Compute Instance Monitoring - Emits metrics about the instance's health, capacity, and performance.
- Bastion - Allows secure shell (SSH) connections to an instance without public IP addresses using the Bastion service.
