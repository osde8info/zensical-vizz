Q

_why cant i make tahoe apps window wider_ ?

A

**_Ah, you've bumped into one of the more frustrating quirks of macOS 26 “Tahoe.” The new Apps panel, which replaced Launchpad, has a resizing issue that’s driving a lot of users up the wall._**

- **Size resets on relaunch**: You _can_ resize the panel temporarily, but it doesn’t remember your changes. Every time you reopen it, it snaps back to its default size.

- **No persistent layout**: Unlike the old Launchpad, there’s no way to save custom widths, folders, or page layouts. It’s a floating window now, not a full-screen grid.

- **Limited customization**: You can move the panel’s position and that _will_ stick, but width and height don’t. So even if you stretch it out, it’ll shrink again next time.
