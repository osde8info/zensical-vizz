apple security vm hypervisor (as used by parallels)

_You can read the `VZVirtualMachine` property [`isSupported`](https://developer.apple.com/documentation/Virtualization/VZMacHardwareModel/isSupported) to check for the availability of virtualization on the system. Calling [`validate()`](https://developer.apple.com/documentation/Virtualization/VZVirtualMachineConfiguration/validate\(\)) checks for the availability of the entitlement the framework requires to run guest OSes._
