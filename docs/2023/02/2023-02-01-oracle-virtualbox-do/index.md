oracle virtualbox does NOT run windows 11 TPM edition - YET !

_Speaking to TechRadar Pro over email, an Oracle spokesperson explained the company is currently working on a “virtual [TPM](https://www.techradar.com/news/forget-tpm-chips-for-windows-11-thats-not-even-the-half-of-it) emulation feature” for VirtualBox 7, which will allow the software to run [Windows 11](https://www.techradar.com/news/windows-11-home-and-pro) in a virtual machine._

_Oracle could not say precisely when the new version will be ready, but wanted to assure customers that the necessary work is underway and that future VirtualBox releases will support Microsoft’s new operating system (which is set to launch on October 5)._
